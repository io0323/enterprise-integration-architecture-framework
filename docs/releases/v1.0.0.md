# v1.0.0

Enterprise Integration Architecture Framework の参照実装の最初の区切り。設計書([EIA-Framework.md](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/docs/architecture/EIA-Framework.md))の各章を動くコードで実証し、全社の連携の実装のテンプレートとして使えるようにした。

## v1.0.0 の意味
- ROADMAP の P00〜P14 をすべて実装した(2026-11-07)。各フェーズの DoD は、それぞれの PR で確かめた。
- **ローカルの参照実装**(Cloud Agnostic。Docker Compose で完結)で、本番の性能や SLA を約束するものではない。性能の値は目安(下の「計測」)。
- 設計書から縮退している範囲は [ADR-0008](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/docs/adr/0008-local-scope-reductions.md) にまとめた(保存データの暗号化・Service Mesh・Event Mesh は範囲外。転送路はローカルでは平文で、任意の `secure` profile で一部を暗号化する)。

## 設計書への反映
実装で分かったことを、設計書の各章の「参照実装の知見」(4.5〜18.1)に、根拠の ADR・Issue・レポートとともに足した(設計書の版 1.1)。章の本文の標準は変えていない。決まっていないことは「未決」、標準を見直すべきだと分かったことは「改訂の候補」と書いた。付録に「章と ADR の対応表」がある。

## 計測
- **障害シナリオ**: [docs/reports/p14-resilience.md](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/docs/reports/p14-resilience.md)(遅延・切断・Broker の停止ごとの期待挙動・観測方法・結果)。CI の `e2e` のジョブで自動で動く。
- **Tier 別の NFR**: [docs/reports/p14-nfr.md](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/docs/reports/p14-nfr.md)。GitHub の標準のランナー(4 コア・15 GiB)で、手動のワークフロー `nfr` で測った。測った 17 の連携のうち 14 が、カタログの SLO を 2 回とも満たした。満たさなかった 3 つは、注文が集中した直後の Saga の待ち行列([#222](https://github.com/io0323/enterprise-integration-architecture-framework/issues/222))。**値は参照実装での目安で、本番の性能値ではない**(ADR-0048)。

## 動かし方
```bash
make setup                # Git のフックと push の設定
make up                   # ローカル基盤(core)。make up PROFILE="order saga" などで profile を足す
./gradlew build           # ビルド・品質の検査・単体テスト・アーキテクチャのテスト
./gradlew integrationTest # Testcontainers の統合テスト
make up PROFILE="order cdc saga batch file b2b saas iot bff" E2E=1 && make e2e   # E2E と障害注入
```
詳しくは [README.md](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/README.md) と [infra/local/README.md](https://github.com/io0323/enterprise-integration-architecture-framework/blob/v1.0.0/infra/local/README.md)。
