# 常駐のプロセスの繰り返しの仕事

見回り・期限切れの処理・消し込みなど、常駐のプロセスが繰り返す仕事は `RepeatingJobs`(`platform/observability`)で動かす。想定していない例外が出ても、止めずに次の回へ進む(#191)。

| アラート | 内容 | 重大度 |
|---|---|---|
| `RepeatingJobFailing` | 繰り返しの仕事が想定していない例外で失敗した(1 件目で発火し、次の失敗がなければ 1 時間で消える) | warning |

## 仕事が想定していない例外で失敗しているとき
DB や下流に届かないなどの想定内の失敗は `Result` で扱うので、ここには数えない。**プログラムの誤りの疑いがある。**

1. ラベル `job`(サービス)と `eia_job_name`(仕事)を確かめる。
2. そのサービスのログで `繰り返しの仕事` を探し、`error.type`(例外の種類)を確かめる。メッセージに業務のデータが入りうるので、ログには種類だけを残している。
3. 同じ入力で失敗し続けていないかを確かめる。ファイルの見回りなら、特定のファイルで止まっている可能性がある(そのファイルの次の処理が進まない)。

プロセスは動き続け、`/health/ready` は UP のままなので、ヘルスチェックでは気づけない。
